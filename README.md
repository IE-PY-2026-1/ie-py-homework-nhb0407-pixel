## 🟦 [1차 과제: V1.0] 시나리오 기획
    
# 개발 내용
변수 활용: goods_name (문자열), purchase_price (정수), profit_rate (실수) 등 다양한 자료형을 정의하고 활용했습니다.
형변환(Casting): 파이썬의 input()은 모든 입력을 문자로 취급하기 때문에, 계산을 위해 int()를 사용하여 숫자로 바꾸어 주는 핵심 문법을 포함했습니다.
f-string 포맷팅: f"{variable:,}"를 사용하여 금액에 콤마(,)를 넣었습니다.
##코드 
# =========================================================
# [Resell-Master V1.0] 굿즈 시세 분석 프로그램
# 작성자: (남현빈)
# 과제 목표: 변수 선언, 입출력, 산술 연산을 이용한 프로그램 구축
# =========================================================
# 1. 인트로 화면 출력
print("=========================================")
print("     Goods Market Analyzer V1.0")
print("      나의 굿즈 수집 포트폴리오")
print("=========================================")
print()
# 2. 데이터 입력 (input 사용)
# input()은 기본적으로 문자열로 받으므로, 숫자는 int()로 형변환이 필요합니다.
goods_name = input("1. 분석할 굿즈 이름: ")
purchase_price = int(input("2. 개당 구매 가격(원): "))
market_price = int(input("3. 현재 장터 시세(원): "))
quantity = int(input("4. 보유 수량(개): "))
# 3. 데이터 연산 (에너지/로직 처리)
# 변수를 활용하여 필요한 수치들을 계산합니다.
total_cost = purchase_price * quantity      # 총 투자 금액
total_value = market_price * quantity       # 현재 총 가치
net_profit = total_value - total_cost       # 예상 순수익
profit_rate = (net_profit / total_cost) * 100  # 수익률(%)
# 4. 최종 결과 리포트 출력
print()
print("-----------------------------------------")
print(f"[ 분석 결과: {goods_name} ]")
print(f"- 총 투자 금액: {total_cost:,}원")
print(f"- 현재 총 가치: {total_value:,}원")
print("-----------------------------------------")
print(f"▶ 예상 순수익: {net_profit:,}원")
print(f"▶ 현재 수익률: {profit_rate:.2f}%")
print("-----------------------------------------")
print("※ V2.0에서 조건문(if)을 이용한 등급 판정 기능이 추가될 예정입니다.")
print("=========================================")

### ✨ 2차 과제 내용

## 🟨 [3차 과제: V2.1] 함수 분리 + 문자열 메소드 + 중복 방지

### ✨ 3차 과제 업데이트 내용

이번 과제는 V2.0 코드를 **함수 분리, 기본값 인수, 중복 방지, 등급 집계** 4가지 방향으로 업그레이드했습니다. 기존에 for문 안에 뭉쳐있던 긴 로직들을 `def` 함수로 분리해 코드 가독성을 높이고, `in` 연산자로 중복 등록을 방지하며, `count()` 메소드로 분석 후 등급 통계까지 출력하는 프로그램으로 발전시켰습니다.

- `def get_grade(ratio)` 함수로 가성비 등급 판정 로직 분리, `return`으로 등급 문자열 반환
- `def calc_profit_rate(retail, market)` 함수로 수익률 계산 로직 분리
- `def is_danger(ratio, limit=2.0)` 기본값 인수로 거품 경보 기준을 유연하게 변경 가능
- `in` 연산자 + `continue`로 중복 굿즈 이름 입력 시 자동 건너뜀
- `grade_log` 리스트에 등급 결과를 저장하고 `count()`로 혜자/적정/거품 등급 개수 집계 출력

---

### 🤖 AI 파트너십 과정

**내용 1: `def` 함수 분리 + 기본값 인수 설계**

- 프롬프트 요약: "지금 for문 안에 if-elif로 가성비 등급을 판정하는 코드가 통째로 들어있어서 너무 길어. `ratio` 값을 매개변수로 받아서 등급 문자열을 `return`하는 함수로 분리하는 법을 알려줘. 수익률 계산도 `def` 함수로 분리하고 싶어. 그리고 거품 경보 기준이 `ratio > 2.0`으로 고정되어 있는데, 기본값 인수를 써서 평소엔 2.0을 기본값으로 쓰고 필요할 때 다른 값을 넣어 호출할 수 있는 함수도 만들어줘."
- 적용 내용: `get_grade(ratio)`, `calc_profit_rate(retail, market)`, `is_danger(ratio, limit=2.0)` 총 3개의 함수를 코드 맨 위에 선언하고, for문 안의 긴 로직을 각 함수 호출 한 줄로 교체함. 특히 `is_danger()`의 기본값 인수 덕분에 사용자가 프로그램 시작 시 경보 기준 배율을 직접 입력할 수 있게 되어 프로그램의 유연성이 크게 향상됨.

**내용 2: `in` 중복 방지 + `count()` 등급 집계 설계**

- 프롬프트 요약: "굿즈 시세 분석 프로그램에서 사용자가 같은 굿즈 이름을 두 번 입력했을 때 중복 등록을 막고 싶어. `in` 연산자랑 `continue`를 같이 써서 이미 등록된 이름이면 건너뛰는 코드를 짜줘. 그리고 분석이 끝난 후 혜자/적정/거품 주의/심각한 거품 등급이 각각 몇 개인지 `count()`로 집계해서 출력하는 방법도 알려줘."
- 적용 내용: `append` 직전에 `if name in goods_names: continue` 한 줄을 추가해 중복 방지 로직을 깔끔하게 구현함. 또한 `grade_log = []` 리스트를 새로 만들어 for문 안에서 매 회차마다 등급을 `append`로 쌓고, 분석 완료 후 `grade_log.count(' 혜자')` 형태로 4개 등급을 각각 집계해 통계 리포트를 출력함. 단순 분석기를 넘어 데이터 통계까지 보여주는 프로그램으로 발전함.

### 🛠️ Troubleshooting & 기술 회고

**문제 1: `is_danger()` 기본값 인수 입력을 비워두면 오류 발생**
- 원인: `input()`으로 `danger_limit`을 입력받을 때 사용자가 아무것도 입력하지 않고 Enter를 누르면 빈 문자열이 반환되어 `float()` 변환 시 `ValueError`가 발생함.
- 해결: `float(input("거품 경보 기준 배율 (기본 2.0): ") or "2.0")` 처럼 `or "2.0"` 을 붙여, 빈 문자열이 들어오면 자동으로 `"2.0"` 문자열로 대체되도록 처리함. `or` 연산자가 빈 문자열을 거짓으로 판단한다는 점을 활용한 방어 코드임.

**문제 2: `break` 발생 시 마지막 굿즈 등급이 `grade_log`에 두 번 저장되는 현상**
- 원인: for문 안에서 `grade_log.append(grade)`를 한 번 실행한 후, `is_danger()` 조건이 참이면 `break` 직전에 `grade_log.append(grade)`를 한 번 더 실행해 중복 저장됨.
- 해결: `break` 직전의 `grade_log.append(grade)` 코드를 제거하고, for문 안의 `append` 한 줄만 남겨두어 해결함. 등급은 이미 위에서 한 번 저장되므로 `break` 전에 추가로 저장할 필요가 없다는 점을 학습함.
